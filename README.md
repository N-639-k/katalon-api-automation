# API Automation Framework - Katalon Studio

This project demonstrates REST API automation using Katalon Studio.

Features implemented:

✔ REST API Testing   
✔ Global Variables  
✔ Test Suite Execution  
✔ HTML Report Generation  

🛠️ Tech Stack
* Tool: Katalon Studio
* Language: Groovy / Java
* Build Tool: Gradle
* Library: Apache HttpClient (built-in)

Test Scenarios Covered

1. GET Users API
2. POST Create User
3. PUT Update User
4. DELETE User
   

Execution

Run Test Suite:
Test Suites → API Regression Suite

 🚦 How to Run
1.  Open the project in Katalon Studio.
2.  Navigate to `Test Suites`.
3.  Select `API_Regression_Suite`.
4.  Click the **Run** button (Chrome or Headless mode).
